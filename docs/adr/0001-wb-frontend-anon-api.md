# Использование неофициального фронтенд-API Wildberries вместо seller API и скрейпинга

Цены для покупателя доступны только из внутреннего фронтенд-API WB (`card.wb.ru/cards/v4/detail`,
обезличенные batch-запросы до 1000 артикулов с параметром `dest`-региона); авторизованный
seller API отдаёт цены продавца, а не покупателя, и требует партнёрского доступа, а HTML-скрейпинг
хрупче и агрессивнее по нагрузке. Сознательно отказываемся от «персональных скидок» («цена для вас»):
они недоступны анонимно, а их извлечение потребовало бы пользовательских cookies — юридически
это хуже (п. 9.9.6 оферты WB запрещает автоматизированный сбор с персонализацией), и доменное
обещание бота — финальная цена региона, а не индивидуальная скидка.

Details: `docs/research/wb-anon-pricing.md`, `docs/research/wb-regions.md`.
