# Интерфейс MarketplaceClient и колонка marketplace с первого дня

Все маркетплейсы подключаются только через интерфейс `MarketplaceClient` (batch-загрузка
карточек и batch-загрузка цен по региону), единственная реализация пока — `WBClient`;
колонка `marketplace` входит в уникальные ключи товаров с самого начала. Решение принято
до появления Ozon, потому что без него артикулы разных площадок столкнулись бы в одном
пространстве идентификаторов и миграция данных на вторую площадку была бы болезненной;
абстракция с одной реализацией — осознанный отказ от «сначала WB-специфичный код, потом
выделим интерфейс».
