# SQLite и однопроцессный контейнер (бот + asyncio-воркер) без Celery/Redis

Для одного глобального цикла проверки с интервалом 45–75 минут и редких batch-запросов
распределённая очередь избыточна: решения о масштабировании через Celery/Redis/несколько
контейнеров отвергнуты в пользу одного Docker-контейнера, где aiogram-бот и воркер живут
в одном asyncio-процессе с SQLite (SQLAlchemy async). Обратный путь (перенос воркера,
замена БД) потребует переписывания слоя доступа к данным и планировщика, поэтому решение
фиксируется заранее.
