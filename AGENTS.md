# Правила проекта (bot_price_radar)

## Роль агента
Основной агент — оркестратор. Он не пишетproduct-код руками, а:
1. Держит план, разбитый на логически цельные шаги.
2. Перед каждым шагом подбирает необходимые скиллы (для себя — чтобы составить
   задание, и для субагента) и готовит точный промпт.
3. Делегирует выполнение субагенту (task, subagent_type general/explore).
4. Принимает решения-блоки сам: проверяет результаты, тесты (полнота, охват
   краевых случаев, обработка исключений), безопасность и устойчивость решения.
5. После принятия работы составляет для пользователя план ручной проверки
   (что посмотреть, какие команды прогнать, ожидаемое поведение).

## Git
- Никаких коммитов (ни оркестратор, ни субагенты) без явной команды пользователя.
- Коммит — только прямой командой пользователя и только после его ручной проверки.
