# 09: Недоступный товар: 48 часов молчания, ровно одно Уведомление, сброс при возврате цены

**What to build:** Товар без Финальной цены в Регионе пользователя (нет цены в ответе; артикул, отсутствующий в ответе, трактуется так же — политика ADR-кандидат 4, `docs/architecture.md` §7) — состояние пары Товар×Регион, Отслеживание не удаляется. Пара копит `unavailable_since`; после 48 часов непрерывной Недоступности (окно из конфига) каждый подписчик получает ровно одно Уведомление («товар недоступен в вашем регионе / снят с продажи»), флаг `unavailable_notified` в Отслеживании гасит повторы. Возврат цены сбрасывает и `unavailable_since`, и флаг — следующая потеря цены снова уведомит. Spec, пользовательские истории 30–32.

**Blocked by:** 08 (воркер Цикла проверки — носитель шага unavailable_due)

**Status:** accepted

- [ ] `apply_batch` ведёт `unavailable_since` по состоянию Недоступности пары; отсутствие nm в ответе (missing) не удаляет Отслеживание и тоже ведёт недоступность (ADR-кандидат 4)
- [ ] Прошагивание окна: `unavailable_due` + `should_notify_unavailable` в Цикле → send по подписчикам с `unavailable_notified == False` → commit ставит флаг; повторно не уведомляет
- [ ] Возврат цены → сброс `unavailable_since` и флага `unavailable_notified`
- [ ] Текст Уведомления: товар недоступен в Регионе пользователя / снят с продажи
- [ ] Unit-тесты `should_notify_unavailable`: 47:59 → False, ровно 48:00 → True, уже уведомлён → False, `unavailable_since=None` → False (spec, «Решения по тестированию» п.1)
- [ ] E2E: 48 ч без цены → ровно одно сообщение на Отслеживание; цена вернулась → снова может уведомить при следующей потере (spec, п.6)
