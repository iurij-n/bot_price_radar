# 08: Воркер Цикла проверки: batch-опрос цен, decide, Уведомления, commit

**What to build:** Фоновая задача воркера живёт по глобальному ритму: сон rand(45–75 мин) (инъектируемый) → активные Регионы → отслеживаемые Артикулы на dest → пакетный опрос `MarketplaceClient` → `apply_batch` → кандидаты Уведомлений → `decide` по Порогу уведомления (0.5% от Цены сравнения, включительно) → `NotifySender.send` («Цена на товар X изменилась на Y%: A → B» + кнопка «Открыть товар») → коммит по результату доставки. Порядок итерации и политика ошибок региона — `docs/architecture.md` §2.6; тест-сценарии — spec, «Решения по тестированию» п.5–6. Воркер не знает ни про SQL, ни про JSON WB, ни про Telegram — только три шва; тестируется без бота.

**Blocked by:** 02 (WBClient/MarketplaceClient), 03 (Store), 04 (NotifySender)

**Status:** accepted

- [ ] Цикл: инъектируемый сон rand(45–75 мин) → §2.6 шаги 1–6 ровно в этом порядке
- [ ] `MarketplaceError` на одном dest → лог + пропуск региона до следующего Цикла, без ретраев; остальные регионы продолжают обработку, цикл не падает
- [ ] Кандидат с решением `decide` (|Δ| ≥ Порога от Цены сравнения, включительно) → send с новой ценой, направлением, размером изменения и кнопкой «Открыть товар»
- [ ] `Delivered` → `commit_notification` (Цена сравнения = уведомлённая цена); `Failed` → без commit (попытка повторится следующим Циклом); `UserBlocked` → `deactivate_user` (ровно один вызов на событие)
- [ ] `price_history` пишется в Цикле через `apply_batch`
- [ ] E2E на фейках трёх швов + реальном domain (spec, п.6): падение > Порога → Уведомление и сдвиг базы; изменение < Порога → молчание, база не сдвинута; ошибка одного dest не валит остальные; `Failed` → база не сдвинута; первый Цикл после добавления через bot-флоу не шлёт ложную дельту (база = цена добавления)
- [ ] Тесты воркера: порядок diff → decide → send → commit; `UserBlocked` → ровно один `deactivate_user` (spec, п.5)
- [ ] Ручной демо-прогон (пометить manual): товар в БД, Порог в `.env` подкручен вниз → реальное Уведомление приходит за один Цикл
