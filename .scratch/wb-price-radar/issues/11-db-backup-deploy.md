## Comments

- `scripts/backup_db.py`: stdlib sqlite3, источник открывается read-only (URI
  `mode=ro`), снимок через `Connection.backup()` — безопасно под записью бота.
  Args: `--db` (default `data/price_radar.db`, см. config.database_path),
  `--dest-dir` (default `backups`), `--keep` (default 7). Ротация по имени
  (`price_radar-YYYYmmdd-HHMMSS.db`, лексикографически = хронологически).
  Ошибки (нет БД, не открылась, не создался каталог, не удалён старый снимок) —
  сообщение в stderr + ненулевой exit; частичный файл снимка удаляется.
- `docker-compose.yml`: сервис `backup` — тот же образ, цикл
  `backup_db.py → sleep 86400`, volumes `./data` (ro по сути) + `./backups`.
  В комментариях — альтернатива с cron на хосте и заметка про права на
  каталог `backups` для пользователя `app` из контейнера.
- `Dockerfile`: добавлен `COPY scripts ./scripts` — иначе скрипта нет в образе.
- Тесты: `tests/scripts/test_backup_db.py` (3 шт: снимок читается +
  integrity_check; ротация 9 старых + новый → остаются 7 самых свежих;
  отсутствующая БД → SystemExit≠0 + stderr).
- README: секции «Деплой на VPS» (резидентный RU IP → docs/research/wb-regions.md,
  сборка dest-ID вручную по §2, compose up, логи, бэкап, восстановление) и
  «Локальная отладка». `.gitignore`: `backups/*.db`.
