# 07: Бот: /region — выбор Региона из справочника с молчаливым сбросом Цены сравнения

**What to build:** Пользователь отправляет `/region` и получает inline-клавиатуру городов из конфигурационного справочника Регионов (город→dest, ADR-кандидат 2 в `docs/architecture.md` §7). Выбор города → `Store.set_region` + молчаливый сброс Цены сравнения каждого Отслеживания на Финальную цену в новом Регионе (политика reset_comparison, ADR-0003); ни одного Уведомления смена Региона не порождает. Если Товар в новом Регионе Недоступный — Цена сравнения становится None. Spec, пользовательские истории 27–29.

**Blocked by:** 05 (бот: добавление Отслеживания; Store.set_region подключается опосредованно через него)

**Status:** accepted

- [ ] [manual/ready-for-human] Оператор вручную собирает dest-ID из браузера (резидентный IP, WB блокирует датацентры) по рецепту `docs/research/wb-regions.md` §2 и заполняет справочник Регионов в конфиге: минимум Курск (дефолт) + 5–15 городов
- [x] `/region` рендерит inline-клавиатуру из конфига-справочника (не из БД и не хардкодом в handler)
- [x] Выбор города → `Store.set_region`; Цены сравнения сброшены на Финальную цену в новом dest, для Недоступного Товара — None
- [x] Смена Региона не отправляет пользователю сообщений Уведомлений (только короткий ответ-подтверждение смены)
- [x] Тесты на fake-швах: смена региона → ноль вызовов send-Уведомлений, `set_region` вызван с корректным набором цен; список `/region` берётся из конфига (spec, «Решения по тестированию» п.1 для `reset_comparison`, п.7 для handler)

## Comments

- Реализовано: `bot/handlers.py::handle_region` + `handle_region_choose`
  (callback `reg:<dest>`), `bot/keyboards.py::region_keyboard` (префикс ✓ для
  текущего dest, codec `encode_region/decode_region`, лимит 64 байт), тексты в
  `bot/messages.py`, поле `BotDeps.regions` (композиция `main.py` => из
  `Settings.regions`).
- Flow: тот же dest → только тост «уже выбран», без fetch и set_region;
  `MarketplaceError` → тост «не удалось проверить цены», dest НЕ меняется;
  пустые Отслеживания → `set_region(..., {})` без перезапроса; успех →
  тост «Регион изменён на <Name>.» + edit-перерисовка клавиатуры с ✓.
  Молчаливость: NotifySender не вызывается ни на одной ветке (тест
  `test_region_change_sends_no_notifications`).
- Готовится к ручной проверке (ready-for-human): первый unchecked-пункт —
  сбор dest-ID оператором и заполнение `REGIONS` в `.env`; код к этому
  готов (клавиатура пустая, если справочник не заполнен).
- Тесты: `tests/bot/test_region.py` (10 шт.); полный прогон — 183 passed.
  Существующие construction-sites `BotDeps` в тестах обновлены (новое
  обязательное поле `regions`).
