# 01: Каркас проекта: конфигурация, две asyncio-задачи, Docker, тестовый харнес

**What to build:** Оператор клонирует репозиторий, кладёт `.env` с токеном бота, запускает `docker compose up` — и получает живой процесс: polling-бот и воркер Цикла проверки стартовали как две asyncio-задачи в одном процессе (ADR-0002, `docs/architecture.md` §1), логи старта видны, по SIGTERM процесс корректно завершается (graceful shutdown). Пустые заглушки бота и воркера — содержимое следующих тикетов. Вся конфигурация читается из `.env` через pydantic-settings с внятными ошибками валидации: токен, Порог уведомления (0.5), лимит активных Отслеживаний (100), окно недоступности (48 ч), диапазон Цикла проверки (45–75 мин), справочник Регионов (город→dest), dest по умолчанию (Курск). Структура пакетов — строго по `docs/architecture.md` §1 с правилом зависимостей (domain — чистое ядро без I/O).
